# 失控寄抽管理系統｜完整版本紀錄

目前最新版：**v46**


## v46｜進行中營收總額＋折扣全抵
### 更新內容
- 營運總覽「進行中套組已產生營收」新增總金額，直接顯示目前所有進行中套組累積銷售額。
- 新增「折扣全抵」銷售情境：當折扣後應收剛好為 0，可不選付款方式直接成立銷售。
- 折扣全抵會記錄為獨立結帳方式，實收與找零皆為 0，且不會自動結束套組。
- 折扣不可超過訂單原價；若應收不為 0，仍必須選擇付款方式並滿足實收金額。
- 新增與編輯銷售都支援折扣全抵，Supabase RPC 與付款方式限制同步更新。


## v45｜老闆到期自動停用
### 更新內容
- 老闆寄抽到期日到達當天起，系統會直接視為「已停用」，並以台灣日期判斷。
- 已停用老闆仍可查看既有套組、銷售、營運總覽與月結歷史資料。
- 已停用老闆禁止新增套組與新增銷售；資料庫端也加入保護，避免繞過前端寫入。
- 左側老闆頁籤與老闆管理頁會顯示「已停用」狀態。
- 若將到期日延長到未來，且原本 active 仍為啟用，系統會自動恢復新增套組與新增銷售。
- 手動 active=停用 仍會維持停用，不會因延長到期日而自動啟用。

## v44｜免單狀態同步＋月結雜項支出
### 更新內容
- 編輯舊銷售改成「免單結束」後，對應套組會自動同步為「免單結束」，不再需要另外勾選結束套組。
- 免單結束的套組結束日期會使用該筆銷售日期；既有免單銷售資料也已補同步。
- 月結新增「雜項支出」扣款，可依老闆與月份輸入金額及備註。
- 月結公式改為「實際應付老闆 = 有效營收 × 90% − 雜項支出」，尚欠再扣除已付老闆金額。
- 月中／本次結款區塊直接提供雜項支出輸入欄位，新增後立即重算實際應付與尚欠。
- 新增雜項支出紀錄表，保留月份、老闆、金額、日期與備註，避免分次結款時重複扣除。
- 若新增雜支後造成已付款高於重新計算的應付金額，月結畫面會標示「已超付」。

## v43｜編輯銷售可直接結束套組
### 更新內容
- 銷售分析的「編輯銷售」補上與新增銷售相同的「直接結束套組」選項。
- 編輯舊銷售時勾選後，儲存即可同步結束對應套組，不必再進套組管理手動修改。
- 一般付款結束為「結束」、免單付款結束為「免單結束」、直購維持「直購」，結束日期使用該筆銷售日期。
- Supabase `update_sale_with_payments` RPC 已同步支援 `p_close_bundle`。

## v42｜銷售紀錄套組名稱同步
### 更新內容
- 銷售紀錄的「品名」改為依 `bundle_id` 即時讀取套組管理目前的最新名稱。
- 套組管理修改品名後，既有銷售紀錄會同步顯示新名稱，不再停留在銷售當下儲存的舊品名。
- 若舊銷售紀錄沒有可對應的套組資料，才退回顯示銷售紀錄原本保存的品名。

## v41｜銷售紀錄精簡＋即時搜尋套組下拉

### 更新內容

- 銷售分析的銷售紀錄移除「實收」與「找零」欄位；結帳時計算功能仍完整保留。
- 「尚餘」欄位保留，用於待定或仍有未收款的銷售辨識。
- 新增／編輯銷售的套組欄位改為可搜尋下拉選單：輸入套組編號、品名或日期時，下方選項即時篩選並直接展開。
- 點選搜尋結果後立即選定套組並帶入一抽價格，不再需要輸入完再另外操作原生下拉選單。
